## Sample barcode convention

- Patient ID: first 12 characters, e.g. `TCGA-AB-2934`
- Sample type code (characters 14-15): `01`-`09` tumor, `10`-`19` normal. In LAML, peripheral blood tumor samples are `03`; normals are `11`.
